This repository is a fork; upstream packages, documentation, and images are not necessarily compatible. Build the CLI from this source and use the published `2026.10.29` image, or build locally with the fixed WeChat package. Both AMD64 and ARM64 images pin WeChat 4.1.13.23 and passed isolated startup smoke checks; those checks do not verify login or account-data behavior.

:::note[Prerequisites]
You need **Docker** running on your machine. On macOS, install [Colima](https://github.com/abiosoft/colima) (`brew install colima && colima start`) or [Docker Desktop](https://www.docker.com/products/docker-desktop/). On Linux, install [Docker Engine](https://docs.docker.com/engine/install/).
:::

## 1. Build this fork's CLI

```bash
git clone --branch main https://github.com/RayDutchman/agent-wechat.git
cd agent-wechat
pnpm --filter cli... --filter shared... install --frozen-lockfile
pnpm --filter @agent-wechat/shared build
pnpm --filter @agent-wechat/cli build
node packages/cli/dist/cli.js --help
alias wx='node packages/cli/dist/cli.js'
```

Use `node packages/cli/dist/cli.js <command> ...` or define the shown shell alias to run the locally built CLI; no global install or npm publication is needed.

## 2. Prepare and start the container

The published `ghcr.io/raydutchman/agent-wechat:2026.10.29` image is available for Linux AMD64 and ARM64. For source builds, provide the verified WeChat 4.1.13.23 `.deb` for your architecture before building; see [Docker Compose setup](/getting-started/container-setup/docker-compose). The default `wx up` image may not contain this fork's server.

When reusing account data, retain its existing token and volume names; do not replace the token. You can use the built CLI below for API interaction after the server is running.

## 3. Log in to WeChat

```bash
wx auth login
```

A QR code is displayed in your terminal. Scan it with WeChat on your phone (tap **+** > **Scan**), then confirm the login.

:::tip
Scan the QR code in WeChat if prompted.
:::

## 4. Interact with WeChat

```bash
# List your chats
wx chats list

# Find a chat by name
wx chats find "John"

# Send a message (--text, --image, or --file)
wx messages send <chatId> --text "Hello from agent-wechat!"
wx messages send <chatId> --image photo.jpg
wx messages send <chatId> --file document.pdf

# Read messages
wx messages list <chatId>

# Download media (images, voice, video) from a message
wx messages media <chatId> <messageId>
```

## 5. View the container via VNC

Open your browser to `http://127.0.0.1:6174/vnc/` and enter the configured token. The provided image supports keyboard and mouse interaction; the source entrypoint retains its read-only default.

## 6. Stop the container

```bash
docker compose --env-file deployment.env stop
```
