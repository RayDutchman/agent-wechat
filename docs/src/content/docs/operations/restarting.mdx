---
title: Restarting & Recovery
description: How to restart the container and recover from common issues.
---

## Restarting the container

### Via the CLI

```bash
wx down && wx up
```

### Via Docker Compose

```bash
docker compose --env-file deployment.env restart agent-wechat
```

Or for a full stop and start:

```bash
docker compose --env-file deployment.env down
docker compose --env-file deployment.env up -d
```

## What happens on restart

- The WeChat session usually persists across restarts. Scan the QR code in WeChat if prompted.
- If the session does expire, the API will report a logged-out status. Run `wx auth login` to sign in again.
- The agent database (`/data/agent.db`) persists across restarts.
- WeChat data persists in the volume mounted at `/home/wechat`; its name depends on the deployment configuration.

## When to restart

Restart the container when:
- The bot stops responding to messages
- You see "no action selected" errors in the logs
- The container appears healthy but WeChat is unresponsive
- After a coordinated token/database credential change; replacing the token alone does not unlock the existing encrypted database

## Wiping WeChat data (fresh start)

For an intentional fresh start, remove the WeChat data volume. **This deletes its messages and media and requires a new login.** Before removing the container, use `docker inspect agent-wechat` to identify the actual named volumes mounted at `/data` and `/home/wechat`; substitute those names below. In local Compose mode, `wx down` only stops the service: remove the stopped container with the same Compose configuration before attempting to remove its volumes.

```bash
# Stop the container
wx down
# or: docker compose --env-file deployment.env down

# Remove the WeChat home volume
docker volume rm <actual-wechat-home-volume>

# Start fresh
wx up
# or: docker compose --env-file deployment.env up -d
```

:::caution
This deletes all WeChat data inside the container including the login session, cached messages, and media. You will need to re-scan the QR code to log in.
:::

## Wiping everything (full reset)

To completely reset both agent data and WeChat data:

```bash
wx down
docker volume rm <actual-agent-data-volume> <actual-wechat-home-volume>
wx up
```

This removes:
- The agent database
- All WeChat user data
- The login session

You will need to sign in again by scanning the QR code. The host token file is separate and is not removed by deleting these volumes.
